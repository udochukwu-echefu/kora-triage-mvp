# Demo limitations

Kora is a portfolio demonstration, not a validated customer product.

- All visible complaints, customer profiles, labels, policies, and evaluation cases are synthetic.
- No support agents or customers have validated the workflow through formal user research.
- The public deployment uses demo authentication and must not receive real customer information.
- Public outbound delivery is simulated. Adapter code is not evidence that live WhatsApp or email delivery is operating.
- The 100-case dataset was authored by the developer and has no independent annotation or inter-rater agreement.
- The fixed 11-case live smoke set is too small to establish general model quality.
- The latest 100-case live attempt is incomplete at 24 of 100 cases.
- SQLite and a single application replica are deliberate demo constraints, not a production scaling design.
- Current latency and token evidence reflects one provider, model, run, and network path.
- No production load test, penetration test, compliance review, uptime history, or customer-impact measurement has been performed.
- Estimated time savings in the interface use a configurable baseline and are not measured business outcomes.

These limitations are part of the evidence. They prevent demo behavior from being presented as production validation.
